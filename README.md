# Robotics Shop — Spring Boot Backend

MVP: каталог, фильтры, JWT-авторизация, корзина, заказ в один клик, админ CRUD.

## Stack
Java 17, Spring Boot 3, PostgreSQL + Flyway, OpenAPI (springdoc), Gradle

## Run (dev)
1) `docker compose up -d`
2) `.\gradlew.bat bootRun`
3) Swagger UI: http://localhost:8080/swagger-ui.html
